# 👨‍🏫 Teachers & Students App

[![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://reactjs.org/)
[![Redux](https://img.shields.io/badge/Redux-764ABC?style=for-the-badge&logo=redux&logoColor=white)](https://redux.js.org/)
[![React Router](https://img.shields.io/badge/React_Router-CA4245?style=for-the-badge&logo=react-router&logoColor=white)](https://reactrouter.com/)
[![MSW](https://img.shields.io/badge/MSW-FF6A33?style=for-the-badge&logo=mockserviceworker&logoColor=white)](https://mswjs.io/)

Приложение для управления студентами и учителями с мок-бэкендом на основе MSW (Mock Service Worker) и генерацией случайных данных через Faker.

---

## ✨ **Возможности**

| Функция | Описание |
|---------|----------|
| **📋 Список студентов** | Просмотр всех студентов с пагинацией |
| **👤 Карточка студента** | Детальная информация о студенте |
| **✏️ Редактирование** | Изменение данных студента |
| **📚 Список учителей** | Просмотр всех учителей |
| **🧑‍🏫 Карточка учителя** | Детальная информация об учителе |
| **🔍 Поиск** | Фильтрация студентов и учителей |
| **🎲 Случайные данные** | Faker генерирует реалистичные имена |

---

## 🛠️ **Технологии**

- **React 18** — библиотека для интерфейсов
- **Redux Toolkit** — управление состоянием
- **React Router v6** — навигация
- **MSW (Mock Service Worker)** — мок-бэкенд
- **@mswjs/data** — база данных в памяти
- **Faker** — генерация случайных данных
- **Styled Components** — стилизация
- **Vite** — сборка проекта
